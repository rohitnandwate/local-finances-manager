Plaid in five steps

  1. Create an app in the Plaid Dashboard.
  2. Enable Transactions (US is the default). Add Investments later if you need holdings.
  3. New Plaid accounts: copy the Sandbox secret. Set PLAID_ENV=sandbox and SANDBOX_PLAID_SECRET. Production secrets only work after Dashboard approval, and they must match PLAID_ENV.
  4. For OAuth banks, add http://127.0.0.1:3000/ as an allowed redirect URI, then optionally set PLAID_REDIRECT_URI to the same URL.
  5. Restart, then connect below or on the Connect tab. Use a Sandbox test bank first.

Full runbook: docs/operations/plaid-sandbox-setup.md.
